# 水贴相机（Android 0.2.22）

[下载最新版 APK](https://github.com/atlasfish/ModelCamera/releases/latest) · [MIT 许可证](LICENSE) · [第三方资源说明](NOTICE.md)

Android 8.0 及以上。一般手机选择 `arm64.apk`（约 27 MB）；旧设备、模拟器或不确定架构时选择 `universal.apk`（约 139 MB）。目前发布的是此前测试使用的 debug 签名 APK。

界面操作图标取自 Google Material Icons 的 outlined Android 矢量资源，遵循 Apache License 2.0；许可文本见 `licenses/material-design-icons-LICENSE`。

一个离线 Android App：把面雕和蓝底水贴拍在同一张照片中，框选一组眼部图案并去蓝底，再把透明贴纸拖到面雕上预览。

## 新增操作

- **不规则面雕描边（0.2.22）**：针对绿垫等背景分离明确的样图，先抑制细网格、选取点击位置所在的连通主体，再在边缘附近做 GrabCut 精修。扩大搜索范围，沿实际外轮廓保留耳部、凹口与连接件，不使用径向规则脸型拟合；低对比肉色垫继续使用原有阴影处理路径。识别范围内的明显窄杂块会被清理，极细真实结构仍可能损失，请检查预览。此路径无需训练集或联网。

- **灰白底纸自适应识别（0.2.21）**：蓝/紫色证据不足时，从照片的平滑浅色区域估计主色，使用厚度筛选和连通区域剔除切割垫细网格，框选与抠图共享同一类颜色模型。局部去底纸与反光判断也支持灰白底纸；利用主要眼部墨迹的包围关系保护浅色眼白，避免把独立眉毛之间的底纸一起保留。新 QQ 例图加入测试素材，7 项设备测试覆盖新图、12 种灰底曝光/色偏组合、旧蓝底、淡紫反光底纸及进入编辑页流程。同色印刷与底纸完全无对比、过曝丢失细节时仍需人工检查。

- **强闪光底纸识别**：有些浅蓝底纸在闪光和白平衡下会拍成浅紫粉色。自动选框和抠图现在能识别这种冷调浅色底纸，并将灰紫眉毛与暖白眼白保留下来；选框会避开底纸边缘并覆盖第一组完整眼眉。被底纸遮住部分网格线时，绿垫也能用露出的完整长线标定。用户提供的绿垫强反光照片已加入首页同框样图和设备回归测试。
- **相机预览比例**：从设备支持的相机输出中选择与照片比例匹配的预览尺寸，按原比例居中裁切到竖屏画面。修复此前把 4:3 预览流直接拉伸到长屏而使网格、面雕变形的问题；拍下的原始照片仍使用完整照片画幅。
- **绿色切割垫标定**：自动识别浅色完整网格线，排除线间较短的十字刻度。当前按用户确认的相邻完整网格线 1 cm 换算；旧版深色圆点切割垫的检测保留。用户提供的绿色切割垫面雕照片已纳入本地算法回归测试。
- **贴纸归档与详情**：管理页长按文件夹可将其中全部贴纸导出为一个 ZIP；多选导出可选逐一保存 PNG 或打包 ZIP。导入入口可选择单张图片、批量 PNG 或 ZIP，ZIP 内的 PNG 会归入以压缩包名称命名的单层文件夹，同名文件夹会复用。点贴纸打开大图详情，查看像素尺寸、文件大小、创建时间、修改时间和尺寸标定，再点「更多操作」进行重命名等处理。旧版贴纸没有单独记录时间，显示原图片文件时间。批量与 ZIP 导入限制数量和大小，并拒绝 ZIP 不安全路径。
- **统一界面样式**：按钮统一 9dp 圆角、卡片和弹窗统一 12dp 圆角，使用浅描边、表面色和点击反馈，去掉卡片的多余阴影；相机页的返回、补光按钮沿用相同线条和圆角。参考 [Android Material 3 的形状与层级](https://developer.android.com/develop/ui/compose/designsystems/material3)及[描边卡片](https://developer.android.com/reference/kotlin/androidx/compose/material3/OutlinedCard.composable)规则。
- **二级贴纸管理**：管理首页把「全部贴纸」「未分类」和自建文件夹展示为带预览的卡片，点开文件夹才显示其中的贴纸；文件夹仅一层。搜索栏可按名称查找文件夹和单张贴纸，在文件夹内可缩小搜索范围。点单张贴纸可再次编辑、重命名、移动、另存副本、导出 PNG 或删除；点「多选」或长按贴纸可勾选多张，底栏支持批量移动、另存副本、导出和删除。导出的 PNG 使用设置页的默认目录，删除文件夹会将贴纸移到「未分类」。
- **整组眼距**：试贴时选中包含左右眼的整组贴纸，App 会寻找两眼之间的透明空隙并设置橙色轴线。下方「整组左右眼 · 眼距」可以向内或向外移动两眼，也能手动移动轴线或点「自动找轴」。调整后的效果随贴纸整体拖动、缩放、旋转，保存进会话并写入导出图；橙色辅助轴线不写入导出图。自动识别不明显时仍可手动开启，先检查轴线位置再调眼距。锁定贴纸时眼距与轴线不可修改，撤回可恢复上一步调整。
- **试贴撤回与不透明度**：试贴页标题栏的「撤回」可恢复上一步操作，包括贴纸拖动、缩放、旋转、移除、锁定，网格与背景调整，以及滑条变化。一次手势或连续拖动滑条记为一步，最多保留 40 步；退出当前试贴后历史不写入会话。选中贴纸时，图层菜单下方显示「贴纸不透明度」滑杆，范围 0–100%；锁定贴纸后仍可调节透明度。预览、导出和已保存会话使用同一透明度。
- **默认导出目录**：点击「导出预览图」直接将 PNG 保存到手机内部存储的 `Download` 目录，自动生成文件名，不再逐次选择保存位置。首页右上角「设置」可更改默认目录；选一次并授权后，重启 App 仍会记住。可点「恢复 Download 目录」切回默认位置。Android 11 及以上的系统文件夹选择器可能不允许直接选择 Download 根目录，此时使用恢复按钮；其他可写文件夹或子文件夹可正常选择。
- **版本识别**：首页和设置页从已安装包读取版本。本次为 **0.2.10**（安装版本号 `12`）；以后每次交付更新递增版本号最后一位，并递增安装版本号。
- **保存会话**：试贴页点「保存会话」并命名。首页「试贴会话」可恢复现场；再次保存会更新当前会话，也可「另存会话」。长按首页的会话可删除。保存包含原照片、每个贴纸的独立透明图片、图层位置/大小/角度/锁定、网格位置/大小/格数/锁定、背景缩放与角度、画布视角、比例标定和描边状态。之后即使删除或修改贴纸库素材，已保存现场仍能恢复。只有点击保存时的状态会写入会话。
- **再次编辑**：管理页点击贴纸 →「更多操作」→「再次编辑」，复用调整贴纸页的切分、橡皮擦、参考线、旋转和锐化。打开已有透明贴纸时不重复去蓝，锐化从 0 开始，避免叠加处理。可「保存修改」覆盖当前素材，或「另存副本」。左右眼拆分会保存为两个副本，原图保留；名称、文件夹、来源与尺寸比例会继承。已摆好的试贴图层不会被替换。
- **单轴定位**：试贴页选中贴纸或网格，下方工具栏显示 X、Y 坐标滑条。X 只调整水平位置，Y 只调整垂直位置；坐标为原照片像素，锁定元素后滑条禁用。
- **0.5° 旋钮**：调整贴纸和试贴页均改用环状旋钮。向上滑动逆时针，向下顺时针；较长的滑动距离才推进一格，每格 0.5°。左右按钮单次调整 −0.5° / +0.5°，「角度归零」恢复 0°。背景与贴纸旋转均保持当前大小，参考网格保持水平垂直。
- **面雕描边（实验功能）**：试贴页点「识别面雕」，可显示或隐藏青绿色边界。自动位置不合适时，点「重选面雕」，再点照片中的面雕中部。采用 [OpenCV GrabCut](https://docs.opencv.org/4.12.0/d8/d83/tutorial_py_grabcut.html) 取得整块面雕，再沿局部颜色与亮度变化寻找闭合边缘。本版比较了直接提高整体分辨率、扩大边缘搜索，以及低分辨率分割配合高分辨率额头细化：前两种会吸入圆点或投影，最终采用第三种，并平滑额头描边和画布曲线。暗部侧脸保持在内，投影保持在外；不强制镜像。描边会随背景缩放和旋转，保存进会话，但不写入导出照片。两张样图已回归；强反光、很暗的面雕或与背景同色时仍可能失败。[MediaPipe Interactive Segmenter](https://developers.google.com/edge/mediapipe/solutions/vision/interactive_segmenter/android) 是后续可验证的候选，尚未在这两张样图上实测，因此本版没有引入模型。

## 使用

1. 将面雕和水贴同时平放在切割垫上，点击「现场拍摄」或「从相册导入」。拍摄界面有固定白色十字与随倾斜移动的彩色十字；两者重合并保持稳定后显示“已水平”。后置相机有闪光灯时，可点右下角「补光」持续照明，拍照时也会保持开启。无闪光灯的设备会显示「无补光灯」。
2. 在照片上框住蓝底内的一组表情。App 会建议首组选框；可拖动选框，拉任一角调整大小。点击「调整抠图」进入全屏编辑页。去蓝强度滑杆就在预览下方，拖动后会重新抠图并刷新预览；此前的擦除、切分位置和画面缩放会保留，更新完成前暂不能保存。可显示覆盖整个预览的 3×3、4×4、5×5 或 6×6 参考网格，也可添加水平、垂直参考线并拖动粉色线或端点微调。网格、参考线和黄色切分线固定在预览画布上，贴纸旋转时不会倾斜；保存时先旋转图案，再按黄色竖线切分。可以整组保存，也可以用自动切分寻找两眼间空隙，或手动移动分界线把左右眼分别保存。橡皮擦可清除多余图案，支持调整笔刷、撤销擦除和清除全部擦除；环状旋钮支持 -180° 到 +180°，每格 0.5°，旋转不会自动改变贴纸的预览倍率，转到斜角超出画面时可双指缩小查看。锐化滑杆实时刷新。按住「对比原图」临时查看未编辑效果。确认后手动点击「保存贴纸」，辅助线不会写入透明 PNG。
3. 保存贴纸并点击「现在试贴」。同框贴纸按这张照片中的像素宽度加入；拆分的左右眼会先分别摆放。试贴页下方有图层菜单：选择「贴纸 1」等图层后，在画布任意位置单指拖动即可相对移动贴纸，双指从任意位置缩放、自由旋转。仍可拖贴纸右上角手柄旋转、右下角手柄缩放，也可用下方环状旋钮和左右 0.5° 按钮微调。选中贴纸后点底栏的锁图标可固定位置、角度与大小；闭锁图标表示已锁定。
4. 在图层菜单选择「参考网格」，可从画布任意位置拖动网格，双指调整网格大小，并单独点「锁定网格」防止误移。网格可隐藏，或选 3×3、4×4、5×5、6×6。网格锁定与贴纸锁定互不影响。
5. 选择「背景照片」后，可双指缩放并自由旋转，也可用下方环状旋钮微调角度，用「－」「＋」微调大小。照片始终围绕画布中心变化，单指拖动或移动双指中心均不会改变照片位置，以免破坏与贴纸、网格的相对位置。「照片复位」恢复原始大小和角度。点固定底栏的「查看」则操作观察视角：单指平移、双指缩放，画面缩放不会改变导出的贴纸尺寸或位置。「画面复位」恢复完整视角。底栏的「新贴纸」会保留已摆好的图层；「导出」保存 PNG，不包含网格与图层选中框。

贴纸保存在 App 私有目录中，历史贴纸可再次使用。首页和试贴页均可打开「管理贴纸」：从相册导入自定义图片（保留原图透明度）、创建单层文件夹、搜索与批量管理；长按文件夹可重命名或删除。没有透明区域的图片也能导入，但原有底色会随贴纸显示。历史贴纸来自另一张照片时按切割垫比例估算初始大小；没有尺寸信息的自定义图片按默认宽度加入，可继续缩放。

首页的「用同框测试照片体验」包含三张用户提供的同框样图，包括这张绿垫强反光水贴照片。先前只有面雕的绿垫照片保留在 [`samples`](samples) 文件夹及设备测试素材中。

## 构建

用 Android Studio 打开本目录，使用 JDK 17 和 Android SDK 34，执行 `:app:assembleDebug`。APK 位于 [`app/build/outputs/apk/debug/app-debug.apk`](app/build/outputs/apk/debug/app-debug.apk)。

命令行构建前配置 JDK 17 的 `JAVA_HOME` 和 Android SDK 的 `ANDROID_HOME`，或在本机 `local.properties` 中设置 `sdk.dir`。Windows 使用：

```powershell
.\gradlew.bat :app:assembleDebug --console=plain
# 仅构建 ARM64 版本
.\gradlew.bat :app:assembleDebug -Parm64Only=true --console=plain
# 构建设备测试 APK
.\gradlew.bat :app:assembleDebugAndroidTest --console=plain
```

macOS / Linux 使用 `./gradlew`。源码中的样图用于离线体验及设备回归测试；其许可范围见 [NOTICE.md](NOTICE.md)。下载包提供 `SHA256SUMS.txt` 供核对文件完整性。

## 验证与边界

- 已在 `Medium_Phone_API_36.1` 模拟器中验证安装、启动、相机预览画幅、文件夹总览与内页、多选反馈、搜索、贴纸详情和贴纸导出到 Download。37 项设备测试覆盖强闪光底纸抠图、预览像素比例、批量移动与另存、ZIP 归档与按压缩包名导入、异常 ZIP 路径拦截、PNG/ZIP 导出，以及两类切割垫的标定。
- 相机补光使用 Camera2 的持续闪光灯模式，预览与拍照采用相同状态，离开拍摄页会关闭。当前模拟器无实体闪光灯，已验证「无补光灯」禁用状态与正常拍照回传；真实 LED 点亮仍需在带闪光灯的手机上确认。
- 两张样图的切割垫网点自动估算约为 28.9 和 27.4 px/mm（App 将照片压到最长边 2048 px 后的值）。这只是垫面参考比例，不能当作面雕曲面的精密测量。
- 新绿垫照片的完整网格线间距为 1 cm；检测得到原图约 78.9 px/mm，App 的 2048 像素工作图约 39.4 px/mm。短十字刻度没有被误作 1 cm。面雕描边覆盖了暗部侧脸，排除了右侧投影；高对比绿垫改善了当前样图的边界识别，但其他颜色、光照或旋转角度仍需实拍验证。
- 这张含水贴纸的新绿垫样图仍露出部分 1 cm 长线，自动标定约 33.7 px/mm（2048 像素工作图）；下方强反光附近的表情也已测试。过曝会使原有墨色和细节变浅，去底纸不能恢复照片里已经丢失的细节。
- 去蓝会从框选区域学习浅蓝或闪光偏紫的底纸颜色，并逐行适应光照；根据完整颜色差异处理透明度，额外保留中性或暖白眼白、清理小杂点和灰黑线条的青色边缘。反光清理会寻找沿“底纸颜色→光源白色”变化的连通亮区，再比较其周围底纸与深色印刷线条，清除更像底纸高光的区域。算法不要求底纸是规则四边形。
- 与底纸明显不同的深蓝或高饱和蓝色瞳孔会保留。若图案与底纸几乎同色，单张照片的颜色信息不足以可靠区分；当前版本尚无局部保留画笔，请降低去蓝强度并仔细检查预览。完全过曝的高光可能遮住原有印刷细节，单张照片无法恢复；反光范围跨过图案或选框跨出底纸时，建议调整光源、重新拍摄或用橡皮擦清理残留。
- 锐化使用保留透明度、保持颜色的亮度反差增强，不会恢复原照片里不存在的细节；高强度可能凸显原图的压缩伪影，建议放大预览后逐步调整。
- 同框拍摄避免两张照片间的缩放差异，但面雕高于切割垫、表面有弧度，最终贴合位置仍需要实物试放确认。
